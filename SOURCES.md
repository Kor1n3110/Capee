# Методика и источники

Все 32 упражнения написаны для этого приложения, тексты чужих курсов не копировались.
Это авторский базовый курс, а не доказанно «лучший» курс и не адаптивный алгоритм keybr.

Изучен README открытого тренажёра [keybr](https://github.com/aradzie/keybr.com):
малый набор букв на старте, постепенное расширение, внимание к точности и статистике.
В нашей реализации используется фиксированная последовательность; адаптивный подбор
слабых клавиш пока не реализован. Рекомендуемый ориентир перехода — 95% точности.

TypingClub и TypingStudy были запрошены, но доступ в облачной среде вернул HTTP 403;
их содержание не использовалось. Заявлять сравнительную оценку этих курсов нельзя.

Python и C++ — набор кода, не обучение программированию. Упражнения развивают набор
скобок, кавычек, операторов и отступов; включают переменные, условия, циклы, функции,
коллекции и итоговую программу. Код в приложении не выполняется.
