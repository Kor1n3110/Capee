# Capee

Нативный клавиатурный тренажёр на Rust + egui. Минималистичный интерфейс,
32 авторских урока: русский, английский, Python, C++. Работает офлайн после сборки.

## Установка Linux x86_64

Распакуйте `dist/capee-linux-x86_64.tar.gz`, откройте терминал в полученной папке
и выполните `sh install.sh`. После этого откройте **Capee** в меню приложений.
Права администратора не нужны. Можно также запустить файл `capee` напрямую.
Нужна Linux-система с glibc 2.39+ и графическим сеансом X11/Wayland, OpenGL,
libxkbcommon. Сборка проверяется на Debian 13; Windows/macOS пакетов пока нет.
Удаление: удалите `~/.local/share/capee/app`, ярлык
`~/.local/share/applications/capee.desktop` и иконку capee.svg из
`~/.local/share/icons/hicolor/scalable/apps`. Историю можно сохранить отдельно.
При нестандартном XDG_DATA_HOME используйте соответствующий каталог.

## Разработка

Установите стабильный Rust. `cargo run --locked`, `cargo test --locked`.
Для Linux нужны libxkbcommon0, libegl1, libgl1 и драйвер OpenGL.
`sh scripts/package.sh` собирает переносимый архив для текущей Linux x86_64 системы.
Зависимости зафиксированы в Cargo.lock. Встроенный шрифт поддерживает кириллицу;
лицензия шрифта находится в assets/FONT-LICENSE.txt.

## Использование

При запуске открывается главная страница. Выберите направление, режим и нажмите
«Начать заниматься». Конкретные уроки также доступны на странице «Уроки». Раскладку ОС
переключайте самостоятельно. Ошибка учитывается и не продвигает курсор.
Enter вводит новую строку, Tab — четыре пробела. Backspace не нужен: неправильный
символ не принимается. Пробелы и отступы кода нужно вводить точно.
Пауза останавливает таймер; уход с тренировки автоматически ставит её на паузу.
Таймер начинается с первого ввода. Скорость — верные символы в минуту;
точность — доля верных нажатий. Новый урок выбирается вручную, рекомендуемая
точность перехода — 95%. Свой текст можно вставить на странице уроков.

Профили и результаты хранятся в `$XDG_DATA_HOME/capee/history.json`
(по умолчанию `~/.local/share/capee/history.json`). История хранится локально,
без аккаунтов и облачной синхронизации. Не запускайте несколько экземпляров
одновременно: совместная запись истории пока не поддерживается.
Звук ошибки опционален, требует `canberra-gtk-play`; фоновой музыки пока нет.
Методика и ограничения источников описаны в SOURCES.md. Код уроков не исполняется.

## Установка на CachyOS (из исходников)

Откройте Konsole и выполните:

```bash
sudo pacman -S --needed git rust base-devel libxkbcommon libx11 libxcursor libxi libxrandr mesa
git clone --branch work https://github.com/Kor1n3110/Capee.git
cd Capee
sh scripts/package.sh
cd dist/capee-linux-x86_64
sh install.sh
```

После установки откройте **Capee** в меню приложений. При сборке нужны Интернет
и несколько минут; после установки приложение работает офлайн. Rust/Cargo нужны
только для сборки. Проверено на Debian 13; на CachyOS отдельно не тестировалось.
Если репозиторий уже скачан: в его папке выполните `git pull --ff-only`, затем
повторите команды начиная с `sh scripts/package.sh`.

## Окно и тема

Нажмите «Развернуть окно» для разворачивания в пределах рабочего стола.
«Полный экран» или F11 скрывает рамку окна; F11 или Esc возвращает обычный режим.
Окно также можно менять по размеру стандартными средствами рабочего стола.
Виртуальная клавиатура центрируется в области тренировки при изменении ширины.
«Тёмная тема» доступна сверху окна и в настройках; выбор сохраняется вместе
с локальными данными и применяется при следующем запуске. Старые файлы истории
продолжают загружаться со светлой темой по умолчанию.

При широком окне рабочая область ограничена 1140 пикселями и расположена по
центру рядом с боковым меню. Карточка упражнения и панель клавиатуры имеют
одинаковую ширину; на высоких экранах клавиши увеличиваются. При меньшей высоте
окна отступы и клавиатура становятся компактнее, длинные упражнения доступны
через вертикальную прокрутку. Пример: assets/wide-screenshot.png.

## Длинные упражнения и движущаяся строка

Каждое из 32 встроенных упражнений содержит ровно 100 слов (групп символов,
разделённых пробелами или переносами). Учебные блоки повторяются до этой длины;
это особенно полезно для закрепления заданного набора клавиш. В кодовых упражнениях
отступы сохраняются, а последний блок может быть обрезан по границе сотого слова:
это материал для набора, а не программа для запуска. Свои тексты сохраняют вашу длину.

Курсор неподвижен по центру карточки, текст смещается после каждого правильного
символа. Ошибка не двигает строку. Перенос строки кода показан символом ↵ и требует
Enter; пробелы и отступы набираются как обычно, Tab вводит четыре пробела.

## Главное меню и бесконечная практика

На главной странице выберите Русский, English, Python или C++, затем режим:
«Урок · 100 слов» или «Бесконечная практика». В обычном режиме можно выбрать
конкретный урок. Нажмите «Начать заниматься»; таймер начнётся с первого ввода.

Бесконечный режим автоматически добавляет новые примеры выбранного курса:
сочетания клавиш и слов перемешиваются, фразы чередуются, в кодовых примерах
меняются блоки, числа и имена переменных. Коллекция исходных фраз конечна, поэтому
отдельные фразы могут повторяться. Ограничения по времени и числу примеров нет;
старый текст удаляется из буфера, статистика продолжает накапливаться.

«В меню» ставит занятие на паузу, «Продолжить занятие» возвращает к нему.
Выбор других параметров или «Начать заниматься» создаёт новую сессию. Для
сохранения результата бесконечной практики нажмите «Завершить и сохранить»;
закрытие окна без завершения не сохраняет активную сессию. В статистике такие
результаты отмечены как «Бесконечный режим». Обычный завершённый урок сохраняется
автоматически. Элементы паузы и завершения расположены над клавиатурой.
